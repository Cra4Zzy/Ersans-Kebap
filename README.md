# Ersan's Kebap – Redesign

Die Website ist als klassische statische Mehrseiten-Website aufgebaut. Sie kann direkt geöffnet oder auf GitHub Pages beziehungsweise einem klassischen Webspace veröffentlicht werden.

## Direkt testen

Die Datei `index.html` per Doppelklick im Browser öffnen. Menü, Animationen und Bewertungs-Slider funktionieren ohne Installation.

## Veröffentlichen

Alle Dateien und Ordner aus diesem Projektordner direkt in das Hauptverzeichnis des Webspaces beziehungsweise GitHub-Repositorys hochladen. Nicht nur den HTML-Ordner hochladen. Die Startseite `index.html` muss im Hauptverzeichnis bleiben.

## Ordnerstruktur

- `index.html` – Startseite für GitHub Pages
- `html/` – Speisekarte, Story, Kontakt, Impressum und Datenschutz
- `css/` – Stylesheet
- `js/` – JavaScript
- `img/` – Bilder und Logos

Die enthaltene Datei `CNAME` ist für `www.ersans-kebap.de` vorgesehen. Beim Hochladen in ein anderes GitHub-Test-Repository muss diese Datei dort entfernt werden.
